## 先講清楚：這個題庫可信到什麼程度

在你用它準備一場要花 1,130 元報名費的考試之前，應該先知道它的極限。

| 事實 | 說明 |
|---|---|
| **沒有任何一題的答案經過逐條核對** | 官方公會題庫釋出年代較久，部分答案可能已因法規修正而過時；社群整理題庫的來源檔更**自述含有 1~2 題錯誤**。 |
| 480 題來自官方 | 中華民國票券金融商業同業公會公開釋出的參考題庫，可信度最高。 |
| 780 題來自社群 | 不具名考生整理的考古題彙編，答案未經官方認可。**UI 上每一題都標示來源**，你隨時知道這題的答案是誰說的。 |
| 460 題可對照現行法條 | 解析引用的條號經比對確認仍存在於現行條文，並把**條文原文直接嵌在題目下方**。 |

這不是免責聲明的客套話 —— 這就是為什麼本專案要做「現行法條對照」這個功能：
**與其要你背一段不知道還算不算數的解析，不如把條文本身擺在你眼前。**

## 考試規則（依官方簡章 115.05.01 版）

| 節次 | 科目 | 題數 | 時間 | 滿分 |
|---|---|---|---|---|
| 第 1 節 | 票券金融法規 | 50 題 | 60 分鐘 | 100 分 |
| 第 2 節 | 票券金融實務 | 50 題 | 60 分鐘 | 100 分 |

**合格標準：兩科總分合計達 140 分，且任一科不得低於 60 分。**

> ⚠️ 網路上（含搜尋引擎摘要、人力銀行、部分補習班網站）常見「實務 80 題 ／ 90 分鐘」
> 「任一科低於 70 分不合格」的說法，是**過時或錯誤**的。以上規格取自證基會官方簡章 PDF。

「總分 140」與「單科 60」是**兩個都要滿足**的條件。法規 95 + 實務 55 = 150 分，
看起來超過 140，實際上不合格 —— 本專案的模擬考會明確告訴你是哪一項沒過
（[`scoring.test.ts`](quiz-app/src/utils/scoring.test.ts) 有一整組測試釘住這個規則）。

- 委託單位：中華民國票券金融商業同業公會
- 執行單位：財團法人中華民國證券暨期貨市場發展基金會
- 法源：票券金融管理法第 12 條第 2 項授權訂定之「票券商負責人及業務人員管理規則」
- 報名費：NT$ 1,130（低收入戶／原住民／身心障礙／支領失業給付者半價）

## 功能

### 三種模式

- **練習模式** —— 自選科目、題數與標籤，作答後立即顯示答案、解析與現行法條。
- **模擬考** —— 依官方結構出卷：**兩科各 50 題**，分節計時 60 分鐘，作答中不顯示答案，
  交卷後套用真實及格規則並指出未達標的原因。
- **錯題複習** —— 錯的題（含跳過）自動進錯題本，答對後自動移除，不會愈積愈多。

### 現行法條對照

解析若寫「依票券金融管理法第 21 條」，題目下方就會出現一個可展開的區塊，
直接顯示**第 21 條的現行條文原文**，並附全國法規資料庫連結。

條文擷取自 55 部法規（2,728 條，2026-07-25）：票券金融管理法及其全部子法、
銀行法、票據法、公司法、證券交易法、洗錢防制法等相關法律，以及金管會令、
票券公會自律規範與央行作業要點。

### 來源徽章

每一題都標示答案出處（官方公會題庫 ／ 社群考古題）與法條引用的稽核狀態。
社群來源的題目在揭曉答案時會額外顯示可信度警語。

### 其他

- 分科成績、正確率、作答時間
- 深色／淺色／跟隨系統主題、三段字級、高對比模式
- 資料存在瀏覽器本機（localStorage），無後端、無追蹤、無帳號

## 題庫組成

```
官方公會參考題庫          480 題
社群考古題整理            955 題  ─┐
  其中與官方重複          175 題  ─┴─→ 併入官方題目，保留其解析與標記
─────────────────────────────────
去重後總計              1,260 題
  票券金融法規            587 題
  票券金融實務            673 題
  附解析                1,193 題 (94.7%)
  附現行法條原文          460 題 (36.5%)
  計算題                   16 題
  來源標為「易錯題」       145 題
  兩份來源答案互相矛盾        1 題  ← 標記「答案有爭議」
```

### ⚠ 1 題兩份來源答案互相矛盾

合併時發現有 1 題，兩份來源對同一題（題幹與選項皆相同）給出**不同的答案**。
這是「其中一方確定是錯的」的直接證據，也是全題庫中最不該照單全收的一批。

早期版本只保留其中一份、把另一份默默丟掉 —— 那等於銷毀證據。
現在這題會：

- 帶有 `答案有爭議` 標籤，可在練習模式篩選出來單獨檢視
- 在揭曉答案時同時顯示**兩方的答案**與各自的來源
- 明確聲明本專案**不裁決誰對** —— 裁決需要查證，而我們沒有做查證

作答這題時，請務必自己去查現行法條。

> **題目指紋 = 題幹 ＋ 選項集合。** 第一版只比題幹，結果把 23 題**完全不同**
> 的題目判為重複並靜默刪除 —— 因為「下列何者為非：」這種通用題幹在本題庫裡是
> 共用的。選項的數值記法（`5%` ／ `0.05` ／ `百分之五`）會先折疊成同一個值，
> 否則同一題會因寫法不同而重複收錄。

### 引用法條稽核結果

以 55 部法規（2,728 條）比對每題解析所引用的條號：

| 狀態 | 題數 | 意義 |
|---|---|---|
| `verified_article_exists` | 460 | 引用的條號在現行條文中仍存在。**不代表答案正確。** |
| `verified_content_match` | 2 | 該文件現行版無條號編制，已確認解析引述的內容仍在現行文件中。 |
| `content_not_found` | 1 | 引述的內容在現行文件中找不到，該規定可能已刪除。 |
| `article_not_found` | 0 | 引用的條號已不存在（過時風險）。目前為 0。 |
| `law_outside_corpus` | 0 | 引用的法規不在語料庫內。已全數補齊，目前為 0。 |
| `cited_document_not_in_corpus` | 2 | 引用函令、自律規範、準則等未收錄文件，**未查證**。 |
| `no_citation` | 795 | 解析未引用可辨識的條號。 |

解析中含「第 N 條」字樣的題共 476 題，工具成功解析 465 題（覆蓋率 97.7%）；
剩下 11 題多為只寫函令字號（如「台財融(四)第 90703584 號函」）而無法規名稱者，
它們被歸為 `no_citation` —— 那代表「沒查到」，**不代表「沒有引用」**。

## 測試策略

132 個測試分四類：

1. **規則正確性**（`scoring.test.ts`）—— 及格規則的每一種邊界：
   總分剛好 140、單科剛好 60、總分 150 但單科 50（**不合格**）、只考一科、零作答。
2. **資料完整性**（`dataset-integrity.test.ts`）—— 答案落在實際存在的選項上、
   同科內無重複題、meta 統計與實際資料相符、現行條文只掛在已確認的條號上。
3. **誠實性守門**（`provenance-honesty.test.ts`）—— 這類測試不檢查功能，
   它檢查**我們有沒有宣稱自己沒做過的事**：
   - `verified_against_official_key` 必須是 0
   - 題目層級不得出現 `answer_verified` / `confidence` 之類自封旗標
   - 社群來源的 note 必須揭露其已知錯誤
   - 條文抽取有缺口的法規，不得產生「該條不存在」的結論
   - 兩份來源答案衝突時必須被保留與計數，不得被合併邏輯默默吃掉
   - **Python 與 TypeScript 的題目指紋必須逐題一致**（`fingerprint-parity.test.ts`）

4. **整合與文件閘門**（`App.test.tsx`、`docs-counts.test.ts`）—— 前者把整個 App
   掛起來跑完練習與模擬考的完整流程（含 StrictMode）；後者比對 README 宣稱的
   每一個統計數字與資料集、以及宣稱的測試數與實際測試數。

第 3 類的存在理由：一個叫「已查證」但其實沒查證的欄位，比沒有這個欄位危險得多 ——
它會讓下一個維護者跳過查證，也會讓使用者把社群整理的答案當成官方認證的答案來背。

第 4 類的 `docs-counts.test.ts` 是被逼出來的：README 的測試數字漂過兩次
（93 → 103 → 122 → 123 → 131 → 實際 132），兩次都是「加了東西但忘了回頭改文件」。
一份寫著錯誤統計的 README，和一個叫「已查證」卻沒查證的欄位是同一種病。

## 已知問題與限制

- **答案未經逐條核對。** 見上方說明。作答時請以現行法條為準。
- **`verified_article_exists` 只驗證「條號存在」，不驗證「條文內容仍支持該答案」。**
  一個條號可以還在，但內容已被修正。這是自動化能做到的上限。
- **跨科重複題**：官方題庫的法規 #174 與實務 #416 是同一題（選項一個寫 `0.15`、
  一個寫 `15%`，數值折疊後指紋相同）。資料層兩份都保留（只練一科的人不該少一題），
  抽題層跨科去重（同一份模擬考卷不會出現兩次）。
- **1 題兩份來源答案互相矛盾**，已標記「答案有爭議」但未裁決。見上方說明。
- **`llms.txt` 放在 `/taiwan-bills-finance-quiz/llms.txt`，不是慣例要求的網域根目錄。**
  GitHub Pages 的專案站台掛在子路徑下，根目錄屬於 `thc1006.github.io` 那個 repo，
  本專案無法提供。依慣例只讀 `https://thc1006.github.io/llms.txt` 的代理會找不到它。
- 仍有 2 題（0.16%）引用的文件取不到全文：財團法人中華民國證券
  櫃檯買賣中心證券商營業處所買賣有價證券業務規則（植根法律網限會員查閱、
  selaw 連結失效、櫃買中心站台改版後路徑不通）。

## 常見問題

**Q：票券商業務人員測驗考幾科？幾題？**
A：兩科。「票券金融法規」50 題、60 分鐘；「票券金融實務」50 題、60 分鐘。兩科皆為選擇題，各滿分 100 分。

**Q：合格標準是什麼？**
A：兩科總分合計達 140 分，**且任一科不得低於 60 分**。兩個條件都要滿足 —— 法規 95 分 + 實務 55 分＝150 分，總分雖然超過 140，但實務科未達 60 分，仍屬不合格。

**Q：誰辦這個考試？**
A：中華民國票券金融商業同業公會委託財團法人中華民國證券暨期貨市場發展基金會（證基會）辦理，採電腦應試。法源是票券金融管理法第 12 條第 2 項授權訂定的「票券商負責人及業務人員管理規則」。

**Q：報名資格？報名費多少？**
A：高中職以上畢業（或公務人員普通／高等考試及格等同等資格）即可報考。報名費新臺幣 1,130 元；低收入戶、原住民、身心障礙者及支領失業給付者半價。

**Q：有歷屆試題（考古題）嗎？**
A：**沒有。** 本測驗採電腦應試，證基會不公布歷屆試題。市面上與網路上流傳的所謂「考古題」，都是考生回憶或票券公會釋出之參考題庫的改編。本專案收錄的是票券公會官方釋出的 480 題參考題庫，以及考生社群整理的彙編，兩者在介面上分別標示。

**Q：命題參考書是哪幾本？**
A：官方簡章載明以《台灣貨幣市場新論》與《票券金融管理法相關法令彙編》兩本為主，由台灣金融研訓院出版。

**Q：這個題庫的答案正確嗎？**
A：**沒有任何一題的答案經過與現行法規逐條核對。** 官方公會題庫釋出年代較久，部分答案可能已因法規修正而過時；社群整理題庫的來源檔更自述含有 1~2 題錯誤。這正是本專案把 328 題的**現行法條原文**直接嵌在題目下方的原因 —— 條文才是權威，解析只是轉述。

**Q：考試時間是「兩科共 120 分鐘」還是「每科 60 分鐘」？**
A：每科各 60 分鐘，是兩個獨立節次，時間不能互相挪用。本專案的模擬考照此分節計時。
